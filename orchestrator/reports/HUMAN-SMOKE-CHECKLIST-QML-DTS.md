# HUMAN-SMOKE-CHECKLIST-QML-DTS

## Цель

Проверить реальный операторский цикл:
видео → click-to-lock → DTS → pack → обучение → best.pt → сравнение → принять/отклонить.

## Перед стартом

- Команда запуска: `PYTHONPATH=src ./tracker_env/bin/python app/main_qml.py`
- Использовать реальные клипы Human (не синтетический smoke).
- Убедиться, что production model (`models/checkpoints/rtx_latest_best.pt` или `models/baseline.pt`) не будет заменена этим smoke — это гарантировано архитектурой, но стоит проверить наглядно.

## Критерии PASS

- Весь цикл дошел до compare result.
- Production model не заменена.
- Статусные сообщения понятны без чтения terminal.
- Нет зависаний UI дольше 3 секунд (кроме ожидаемого heavy training).
- Все ошибки объяснены в UI.
